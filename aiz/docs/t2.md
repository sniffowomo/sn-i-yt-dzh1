## Defining and Using Colors in Bash

Bash (and any other shell that writes to an ANSI‑compatible terminal) can change text colour by emitting **ANSI escape sequences**.  
The general form of a colour escape is:

```bash
echo -e "\033[<code>mYour text here\033[0m"
```

* `\033[` – the escape introducer (`\e[` works as well)  
* `<code>` – one or more numeric codes that tell the terminal what colour/style to use  
* `m` – terminates the sequence  
* `\033[0m` – resets all attributes back to the terminal’s default (always put this after coloured output so later text isn’t unintentionally coloured)

---

### 1. Basic foreground colour codes

| Colour   | Code |
|----------|------|
| Black    | 30   |
| Red      | 31   |
| Green    | 32   |
| Yellow   | 33   |
| Blue     | 34   |
| Magenta  | 35   |
| Cyan     | 36   |
| White    | 37   |

**Example – red text**

```bash
echo -e "\033[31mThis is red text\033[0m"
```

---

### 2. Making the codes reusable with variables

Putting the escape sequences in variables makes scripts cleaner and avoids repetition.

```bash
# Text colour variables
BLACK='\033[30m'
RED='\033[31m'
GREEN='\033[32m'
YELLOW='\033[33m'
BLUE='\033[34m'
MAGENTA='\033[35m'
CYAN='\033[36m'
WHITE='\033[37m'

# Reset (back to default colour/attributes)
RESET='\033[0m'

# Example usage
echo -e "${RED}Error:${RESET} Something went wrong."
echo -e "${GREEN}Success:${RESET} All done."
```

---

### 3. Bright (high‑intensity) colours

Add **60** to the normal colour code to get the bright version (e.g., 90‑97 for foreground).

| Bright colour | Code |
|---------------|------|
| Bright Black (gray)   | 90 |
| Bright Red            | 91 |
| Bright Green          | 92 |
| Bright Yellow         | 93 |
| Bright Blue           | 94 |
| Bright Magenta        | 95 |
| Bright Cyan           | 96 |
| Bright White          | 97 |

```bash
BRIGHT_RED='\033[91m'
echo -e "${BRIGHT_RED}This is bright red${RESET}"
```

---

### 4. Background colours

Background colours use codes **40‑47** (normal) and **100‑107** (bright).

| Background | Code |
|------------|------|
| Black      | 40   |
| Red        | 41   |
| Green      | 42   |
| Yellow     | 43   |
| Blue       | 44   |
| Magenta    | 45   |
| Cyan       | 46   |
| White      | 47   |
| Bright Black (gray) | 100 |
| … (add 60 to the normal background code for the bright versions) |

**Example – white text on a blue background**

```bash
WHITE_ON_BLUE='\033[37;44m'   # 37 = white fg, 44 = blue bg
echo -e "${WHITE_ON_BLUE}White on blue${RESET}"
```

---

### 5. Text attributes (bold, underline, etc.)

You can combine multiple codes by separating them with semicolons.

| Attribute | Code |
|-----------|------|
| Reset / normal          | 0 |
| Bold / increased intensity | 1 |
| Dim                     | 2 |
| Underline               | 4 |
| Blink (slow)            | 5 |
| Reverse video (swap fg/bg) | 7 |
| Hidden                  | 8 |

**Example – bold, underlined, green text**

```bash
BOLD_UNDERLINE_GREEN='\033[1;4;32m'
echo -e "${BOLD_UNDERLINE_GREEN}Important${RESET}"
```

---

### 6. Putting it all together – a small helper function

If you frequently need coloured output, a tiny helper makes life easier:

```bash
color_echo() {
    local color=$1   # e.g., RED, GREEN, BOLD_YELLOW
    shift
    local text="$*"
    local esc="${!color}"   # indirect expansion to get the variable value
    echo -e "${esc}${text}${RESET}"
}

# Define the colour variables (as shown earlier)
RED='\033[31m'
GREEN='\033[32m'
BOLD_YELLOW='\033[1;33m'
RESET='\033[0m'

# Use the helper
color_echo RED "This is an error message"
color_echo GREEN "All good!"
color_echo BOLD_YELLOW "Warning: check your input"
```

## Quick Reference Cheat‑Sheet

```bash
# Reset
RESET='\033[0m'

# Foreground (normal)
BLACK='\033[30m'   RED='\033[31m'   GREEN='\033[32m'   YELLOW='\033[33m'
BLUE='\033[34m'    MAGENTA='\033[35m' CYAN='\033[36m'   WHITE='\033[37m'

# Foreground (bright)
BRIGHT_BLACK='\033[90m'   BRIGHT_RED='\033[91m'   BRIGHT_GREEN='\033[92m'   BRIGHT_YELLOW='\033[93m'
BRIGHT_BLUE='\033[94m'    BRIGHT_MAGENTA='\033[95m'   BRIGHT_CYAN='\033[96m'   BRIGHT_WHITE='\033[97m'

# Background (normal)
BG_BLACK='\033[40m'   BG_RED='\033[41m'   BG_GREEN='\033[42m'   BG_YELLOW='\033[43m'
BG_BLUE='\033[44m'    BG_MAGENTA='\033[45m' BG_CYAN='\033[46m'   BG_WHITE='\033[47m'

# Background (bright)
BG_BRIGHT_BLACK='\033[100m'   BG_BRIGHT_RED='\033[101m'   # … etc.

# Attributes
BOLD='\033[1m'   DIM='\033[2m'   UNDERLINE='\033[4m'   REVERSE='\033[7m'
```

You can now mix and match any of these variables inside `echo -e` (or `printf`) to produce coloured, styled terminal output. Remember to always end with `${RESET}` (or `\033[0m`) so subsequent text isn’t unintentionally coloured. Happy scripting!

Below is a complete, self‑contained guide to defining and using **bright (high‑intensity) colors** in Bash. It includes the ANSI escape‑code table, example usage, and a convenient way to store the codes in variables for reuse.

---

## 1. Why “bright” colors work

Bash (and any terminal that understands ANSI escape sequences) changes text colour by printing a special control string:

```
\033[ <attributes> ; <foreground> ; <background> m
```

* `\033` (or `\e`) is the ESC character.
* The **attribute `1`** turns on “bright” / “high‑intensity” mode.
* The **foreground colour numbers 30‑37** are the normal colors; adding **60** (i.e. 90‑97) gives the bright versions.
* `\033[0m` (or `\e[0m`) resets all attributes back to the terminal defaults.

---

## 2. Bright‑color escape sequences

| Bright colour | Escape sequence (quoted for Bash) | Numeric code |
|---------------|-----------------------------------|--------------|
| Black         | `\033[1;90m`                      | 90 |
| Red           | `\033[1;91m`                      | 91 |
| Green         | `\033[1;92m`                      | 92 |
| Yellow        | `\033[1;93m`                      | 93 |
| Blue          | `\033[1;94m`                      | 94 |
| Magenta       | `\033[1;95m`                      | 95 |
| Cyan          | `\033[1;96m`                      | 96 |
| White         | `\033[1;97m`                      | 97 |

*The leading `1;` is the “bright” attribute; you could also write just `\033[90m` etc., but `1;` guarantees the high‑intensity version on all terminals.*

---

## 3. Quick one‑liner examples

```bash
# Bright red text
echo -e "\033[1;91mThis is bright red\033[0m"

# Bright green followed by normal text
echo -e "\033[1;92mBright green\033[0m and normal again"
```

`-e` tells `echo` to interpret back‑slash escapes.

---

## 4. Storing colours in variables (recommended)

Putting the codes in variables makes scripts cleaner and avoids repetition.

```bash
# Define bright colour variables
BRIGHT_BLACK='\033[1;90m'
BRIGHT_RED='\033[1;91m'
BRIGHT_GREEN='\033[1;92m'
BRIGHT_YELLOW='\033[1;93m'
BRIGHT_BLUE='\033[1;94m'
BRIGHT_MAGENTA='\033[1;95m'
BRIGHT_CYAN='\033[1;96m'
BRIGHT_WHITE='\033[1;97m'

# Reset code
RESET='\033[0m'

# Example usage
echo -e "${BRIGHT_BLUE}Bright blue text${RESET}"
echo -e "${BRIGHT_YELLOW}Bright yellow${RESET} and normal text"
```

You can also combine colours with other attributes (bold, underline, etc.) by adding more numbers separated by semicolons, e.g.:

```bash
# Bright cyan, underlined
UNDERLINE_BRIGHT_CYAN='\033[4;1;96m'
echo -e "${UNDERLINE_BRIGHT_CYAN}Underlined bright cyan${RESET}"
```

---

## 5. A tiny helper function (optional)

If you need to colour arbitrary strings often, a small function saves typing:

```bash
colorize() {
    local colour=$1   # e.g. BRIGHT_RED
    local text=$2
    echo -e "${!colour}${text}${RESET}"
}

# Usage
colorize BRIGHT_MAGENTA "Hello in bright magenta!"
```

`"${!colour}"` expands the variable whose name is stored in `$colour`.

## 6. Full “cheat‑sheet” script you can source

Create a file called `bright-colors.sh` and source it in any script you write:

```bash
# bright-colors.sh
#!/usr/bin/env bash
# Bright (high‑intensity) ANSI colour definitions

BRIGHT_BLACK='\033[1;90m'
BRIGHT_RED='\033[1;91m'
BRIGHT_GREEN='\033[1;92m'
BRIGHT_YELLOW='\033[1;93m'
BRIGHT_BLUE='\033[1;94m'
BRIGHT_MAGENTA='\033[1;95m'
BRIGHT_CYAN='\033[1;96m'
BRIGHT_WHITE='\033[1;97m'

RESET='\033[0m'
```

Then in any script:

```bash
#!/usr/bin/env bash
source ./bright-colors.sh

echo -e "${BRIGHT_GREEN}All good!${RESET}"
```

---

## 7. Recap – the essential steps

1. **Use the escape sequence** `\033[1;9Xm` where `X` is 0‑7 for the colour you want.
2. **Reset** with `\033[0m` after the coloured text.
3. **Optionally store** the sequences in variables for readability and reuse.
4. **Print** with `echo -e` (or `printf`) so the escapes are interpreted.

That’s everything you need to define and use bright colours in Bash!
