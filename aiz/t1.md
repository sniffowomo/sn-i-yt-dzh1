## 2️⃣ Core `ipinfo` commands

| Command | What it does | Example |
|---------|--------------|---------|
| **Lookup a single IP** | Returns full JSON (or pretty) data for the given address. | ```bash<br>ipinfo 8.8.8.8<br>``` |
| **Show your own IP** | Queries the API for the IP of the machine you’re running on. | ```bash<br>ipinfo myip<br>``` |
| **Bulk lookup** | Reads a list of IPs (one per line) from *stdin* or a file and returns data for each. | ```bash<br>ipinfo bulk < ips.txt<br>``` |
| **Summarize a file / CIDR** | Produces aggregated statistics (countries, ASNs, companies, etc.) for many IPs. | ```bash<br>ipinfo summarize ips.txt<br>ipinfo summarize 8.8.8.0/24<br>``` |
| **Map IPs** | Opens a browser window with an interactive map of the supplied IPs. | ```bash<br>ipinfo map ips.txt<br>``` |
| **Print IP list from CIDR / range** | Expands a CIDR or IP range into a plain list of addresses. | ```bash<br>ipinfo prips 8.8.8.0/24<br>``` |
| **Filter IPs (`grepip`)** | Pulls out IPs that match a given field/value from any input source. | ```bash<br>ipinfo grepip -f country -v US < logs.txt<br>``` |
| **Convert CIDR ↔ range** | Handy utilities for CIDR‑range conversions. | ```bash<br>ipinfo cidr2range 8.8.8.0/24<br>ipinfo range2cidr 8.8.8.0-8.8.8.255<br>``` |

*All commands share the same global options:*

```bash
ipinfo [global options] <command> [command options] [arguments]
```

| Global option | Effect |
|---------------|--------|
| `-j`, `--json` | Output raw JSON (default is pretty‑printed). |
| `-c`, `--csv`  | CSV output (useful for spreadsheets). |
| `-p`, `--pretty` | Human‑readable, colored output (default). |
| `-f <field>`, `--field <field>` | Return only the specified field(s) (comma‑separated). |
| `--nocache` | Bypass the local cache and force a fresh API request. |
| `-h`, `--help` | Show help for the CLI or a specific sub‑command. |
| `-v`, `--version` | Show the CLI version. |

## 3. Get only the IP address (no extra fields)

```bash
curl ipinfo.io/ip
# or
ipinfo ip
```

---

## 4. Bulk lookup (many IPs at once)

Create a plain‑text file (`ips.txt`) with one IP per line, e.g.:

```
8.8.8.8
1.1.1.1
208.67.222.222
```

Then run:

```bash
ipinfo bulk ips.txt
```

You can also pipe data:

```bash
cat ips.txt | ipinfo bulk -
```

*Options*: `-j` for JSON output, `-c` for CSV, `-p` to pretty‑print, etc.

---

## 5. Summarize a list / range of IPs  

The `summarize` sub‑command aggregates statistics (top countries, cities, ASNs, etc.) for up to 1 000 IPs.

```bash
# Single range
ipinfo summarize 149.234.16.0-149.234.31.255

# Multiple ranges / individual IPs together
ipinfo summarize 149.234.16.0-149.234.31.255 212.64.224.0-212.64.255.255 8.8.8.8
```

Add `-j` for JSON, `-c` for CSV, or `-p` for a pretty table.

---

## 6. Map IPs (interactive map in your browser)

```bash
# From a file
ipinfo map ips.txt

# Directly from a list
ipinfo map 8.8.8.8 1.1.1.1
```

A browser window opens showing the geographic locations of the supplied IPs.

| `ipinfo asn <ASN>` | Look up details for an Autonomous System Number. |

## 4. Basic usage – Getting system information with `inxi`

| Command | What it shows |
|---------|---------------|
| `inxi` | A concise summary of the most important system details. |
| `inxi -F` | Full output – hardware, OS, kernel, desktop, etc. |
| `inxi -c` | CPU information (model, cores, speed, temperature). |
| `inxi -m` | Memory (RAM) details. |
| `inxi -D` | Disk/partition information. |
| `inxi -N` | Network interfaces and IP addresses. |
| `inxi -G` | Graphics (GPU, driver, resolution). |
| `inxi -S` | Operating system and kernel version. |
| `inxi -A` | Audio devices. |
| `inxi -U` | Update `inxi` to the latest version (also pulls the latest man page). |
| `man inxi` | Full manual with every flag and option. |

**Examples**

```bash
# Quick overview
inxi

# Detailed hardware report
inxi -F

# Only CPU and temperature
inxi -c -t

# Show all info, but hide the less‑useful “system” line
inxi -Fxx
```

You can combine flags; for instance, `inxi -c -m -D -N` will display CPU, memory, disk, and network information in one go.
